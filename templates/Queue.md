# Queue

**Present tense only.** Who is working on what, what is blocked, and what one
project needs from another. What *happened* goes in a project's log, never here.

Read this at session start. Update it before you finish. Both are mandatory.

## Active

One row per agent currently holding a project. If you are working, you are here.

| Project | Agent | Working on | Since |
|---|---|---|---|
|  |  |  |  |

## Idle

Projects with no agent holding them.

| Project | Left at | Since |
|---|---|---|
|  |  |  |

## Waiting on the owner

**Decisions only.** Money, anything outward-facing, anything irreversible,
anything that is a matter of their taste. Project activity is state, not a
question — it does not belong here.

| # | What is needed | Why only they can settle it | Raised |
|---|---|---|---|
|  |  |  |  |
